# HAUS180 Motion Lab

Laboratorio visual independiente para probar animaciones de entrada de HAUS180 sin modificar el producto principal.

## Demo

`index.html` funciona sin dependencias ni compilación.

- Logo vectorial HAUS derivado de la referencia corporativa.
- Transiciones de fotografías recortadas dentro de las letras.
- Interacción con el cursor y expansión al hacer clic.
- Reinicio: botón, tecla R o Esc.
- Respaldo visual animado si faltan fotografías.

Para incluir fotografías, crea `images/` con estos nombres: `01-caribe.jpg`, `02-torre.jpg`, `03-barranquilla.jpg`, `04-muelle.jpg`, `05-costa.jpg`, `06-final.jpg`. Usa imágenes con derechos de uso apropiados y ubicaciones verificadas.

## Publicación

En GitHub, abre **Settings → Pages → Build and deployment** y selecciona **Deploy from a branch**, `main` y `/ (root)`. Cuando la publicación termine, el demo estará en `https://mariamanjarres04.github.io/haus180-motion-lab/`.

La integración con el frontend principal requiere una revisión y aprobación posteriores.
